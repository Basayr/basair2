# بصائر — Basair2

تطبيق أندرويد لدراسة القرآن الكريم، بواجهة عربية وبحث حرفي في النص العثماني.

## الموجود حالياً
- مشروع Android أصلي باستخدام Kotlin وJetpack Compose.
- واجهة أولية للبحث عن كلمة أو عبارة.
- البحث يستخدم مطابقة Unicode حرفية عبر `contains` ولا يحذف التشكيل أو يبدّل الحروف.
- ملف القرآن يُنزّل أثناء البناء ويُتحقق من حجمه وبصمة SHA-256 قبل تضمينه في التطبيق؛ بعد تثبيت APK يعمل النص دون اتصال بالإنترنت.

## مصدر نص القرآن
النص هو Tanzil Quran Text (Uthmani, Version 1.1)، محفوظ كما هو دون تعديل. مصدر المشروع وشروطه:
- https://tanzil.net/
- https://tanzil.net/docs/Text_License
- https://tanzil.net/updates/

يُحفظ إشعار الحقوق الأصلي داخل ملف النص. النسخة المستخدمة من مرآة موثقة تطابق ملف Tanzil الأصلي عند التحقق المنشور بتاريخ 2026-10-08؛ حجم الملف 1,334,737 بايت وبصمة SHA-256:
`ac0724796cbbda0f4801470fbbd11d0f3c5802067bae0493466d0128b0c667af`.

## البناء
يتطلب JDK 17 وGradle 8.9 وAndroid SDK 35. شغّل:

```bash
gradle assembleDebug
```

ينزّل Gradle ملف النص الموثق تلقائياً إلى `app/src/main/assets/quran-uthmani.txt` قبل بناء التطبيق. ينتج APK في:
`app/build/outputs/apk/debug/app-debug.apk`.

## ما لم يكتمل بعد
هذه نسخة تأسيسية وليست إصداراً نهائياً: يلزم اختبار بناء APK فعلياً، ثم إضافة تصفح السور والآيات، وأرقام صفحات المصحف، والعلامات المرجعية، وتحسين شكل عرض الصفحات.
