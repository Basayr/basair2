# بصائر 2 — Basair2

تطبيق أندرويد عربي لدراسة القرآن الكريم وقراءته والبحث في نصه بالرسم العثماني.

## ما يتضمنه المشروع حالياً

- تطبيق أصلي مبني بـ Kotlin وJetpack Compose.
- واجهة عربية بألوان خضراء هادئة ولمسات ذهبية، مع رأس تعريفي وشريط تنقّل سفلي.
- تبويب المصحف مع التنقل بين صفحات مصحف المدينة النبوية، رواية حفص عن عاصم.
- تبويب النص والبحث: اختيار السورة، عرض الآيات، تكبير الخط، البحث الحرفي، وحفظ موضع القراءة.
- تبويب التدبر والإحصاء: إحصاء الآيات والكلمات والحروف، الحروف المنقوطة وغير المنقوطة ومجموع النقاط، تكرار الحروف والكلمات، العبارات الثلاثية المتكررة، البحث الحرفي، وإحصاء كل آية.
- أيقونة تطبيق مخصصة مرتبطة في AndroidManifest.

## النص القرآني

يُضمّن ملف Tanzil Quran Text (Uthmani, Version 1.1) في APK بعد تنزيله أثناء البناء والتحقق من الحجم وبصمة SHA-256. بعد التثبيت، يعتمد تبويب النص والبحث والإحصاءات على الملف المحلي.

المصدر وشروط الاستخدام:
- https://tanzil.net/
- https://tanzil.net/docs/Text_License/
- https://tanzil.net/updates/

الحجم المتوقع: 1,334,737 بايت.
SHA-256: `ac0724796cbbda0f4801470fbbd11d0f3c5802067bae0493466d0128b0c667af`.

## ملاحظة مهمة حول صفحات المصحف

صفحات المصحف المصورة بصيغة SVG تُحمّل حالياً من خدمة خارجية عند فتح الصفحة؛ لذلك يلزم اتصال بالإنترنت لعرضها، ولا ينبغي اعتبار هذا الجزء متاحاً دون اتصال. أما نص القرآن المستخدم في البحث والإحصاءات فيُضمّن محلياً.

## منهج الإحصاء وحدوده

يتم فصل علامات التشكيل عند عدّ الحروف، وتُحصى أشكال الحروف كما تظهر في النص دون دمج التاء المربوطة أو الألف المقصورة أو صور الهمزة. وتُحسب النقاط وفق جدول للحروف العربية الشائعة. هذا تقدير آلي معلن المنهج، وليس تحقيقاً متخصصاً نهائياً لجميع علامات الرسم العثماني؛ ينبغي مراجعة النتائج المتخصصة قبل اعتمادها علمياً.

## البناء

يتطلب JDK 17 وGradle 8.9 وAndroid SDK 35:

```bash
gradle assembleDebug
```

ينتج ملف APK في:
`app/build/outputs/apk/debug/app-debug.apk`.

ويقوم GitHub Actions ببناء نسخة Debug تلقائياً عند كل تحديث على الفرع `main`.

## ما يحتاج إلى استكمال قبل الإصدار النهائي

- اختبار APK على أجهزة أندرويد فعلية ومقاسات شاشة مختلفة.
- تضمين صفحات المصحف محلياً بعد التحقق من مصدرها وترخيصها وحجمها، إن أمكن، لدعم القراءة دون إنترنت.
- تدقيق خوارزمية عدّ الحروف والنقاط مع مرجع متخصص في الرسم العثماني.
- تحسين اختبارات المطابقة الكاملة للنص، وإضافة اختبارات آلية لنتائج الإحصاء.
- اختبار الأيقونة ومظهر التطبيق على الشاشة الرئيسية فعلياً.
